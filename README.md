#### [PDF to JPG Sandbox](https://github.com/devzoltan/pdf-to-jpg-sandbox)

Convert PDF pages to JPG – every file is rendered in a **fresh, network-less, read-only Docker container** that is destroyed right afterwards. Nothing is stored.

- 🔒 Hardened sandbox: no network, non-root, read-only, resource & time limits
- 🔄 Worker image rebuilt before every job (latest security updates)
- 🧪 Real-Docker integration tests + Playwright, CI on GitHub Actions
- 🌐 English / German UI, accessible and responsive
