#### [PDF to JPG Sandbox](https://github.com/devzoltan/pdf-to-jpg-sandbox/blob/main/README.de.md)

PDF-Seiten in JPG umwandeln – jede Datei wird in einem **neuen Docker-Container ohne Netzwerk und mit schreibgeschütztem Dateisystem** gerendert, der danach sofort entfernt wird. Es wird nichts gespeichert.

- 🔒 Abgeschotteter Worker: kein Netzwerk, kein root, read-only, Ressourcen- und Zeitlimits
- 🔄 Worker-Image wird vor jedem Auftrag neu gebaut (aktuelle Sicherheitsupdates)
- 🧪 Integrationstests mit echtem Docker + Playwright, CI mit GitHub Actions
- 🌐 Oberfläche auf Englisch / Deutsch, barrierearm und responsiv

`TypeScript` `Fastify` `React` `Docker` `Poppler`
